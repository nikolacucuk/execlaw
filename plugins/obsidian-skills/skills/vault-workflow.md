# Vault Workflow

Purpose: shape answers into vault-ready notes that are easy to keep and find in Obsidian.

Workflow:
1. Start with a clear H1 title.
2. Add a short context block (2-4 lines).
3. Use sections with explicit headings.
4. End with "Next actions" and optional "Questions".

Formatting rules:
- Use Markdown compatible with Obsidian.
- Prefer checklists for actionable items.
- Include candidate tags (3-7) at the bottom.
- Suggest wikilinks when concepts likely connect to existing notes.

Quality bar:
- The note should be useful after a single paste into a vault.
- Avoid fluff and avoid repeating the same idea.
