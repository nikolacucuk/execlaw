# Atomic Notes

Purpose: transform broad input into small, reusable notes that can be linked over time.

Method:
- Capture one core idea per note.
- Use an explicit claim sentence near the top.
- Add 2-5 supporting points only.
- Add a short "Links" section with related-note suggestions.

Title guidance:
- Prefer descriptive titles over vague labels.
- Keep titles stable so links remain meaningful.

Output shape:
- Return one primary note.
- If the source clearly contains multiple independent ideas, include a short list of proposed child notes.

Constraints:
- Do not invent facts.
- Keep each note compact and referenceable.
